## 🧑‍💻 About Me

Full-stack Java developer **specializing in backend systems** — building resilient Spring Boot microservices, event-driven Kafka pipelines, and distributed architectures on AWS. Equally comfortable building React frontends when the team needs it.

Currently shipping fintech software at **Cognizant Technology Solutions** for a US-based client, working with high-throughput systems that process real financial transactions.

- ▸ Designing fault-tolerant microservices with **Circuit Breaker, Saga, and CQRS** — handling real financial transactions at scale
- ▸ Securing fintech APIs with **OAuth 2.0 / JWT** and **Spring Security** in production
- ▸ Owning production reliability — **Splunk** for logging, **Prometheus + Grafana** for metrics and alerting
- ▸ Shipping faster with **AI-assisted development** (Claude Code) and automation
